Pour qui, pour quand

L'année qu'on aura oubliée dans dix ans

Les grandes années, on s'en souvient. Ce qui s'efface, ce sont les petites choses : la phrase que disait la petite à quatre ans, le surnom du chat, ce qu'on mangeait le vendredi soir. Ce livre les garde. Par défaut, c'est l'année qui vient ; vous pouvez aussi raconter une année déjà passée.

Une année de changements

Une naissance, un déménagement, un nouveau travail, une année à l'étranger. Celle dont on voudra se souvenir de chaque détail.

Une année ordinaire

Les disputes pour la télécommande, les dimanches, les rentrées. C'est souvent elle qu'on regrette le plus, plus tard.

Ce qu'on y raconte

Douze mois, vus par chacun

Un chapitre par mois. Chaque mois tire six à huit questions dans les thèmes de la famille : le quotidien, les premières fois, les mots d'enfants, l'école et le travail, les fêtes, les vacances, les saisons, les lieux, les amis, ce qui a changé. Les enfants ont leurs propres questions, courtes, pour répondre en trente secondes depuis le téléphone d'un parent. Le livre s'ouvre sur « Notre famille », qui présente chacun.

À quoi ressemble le livre

Un mois, toutes les voix

Dans chaque mois, les voix se suivent, signées du prénom. Les enfants gardent leurs mots. Une photo toutes les quatre pages, dans le texte. Un invité d'un moment, un grand-parent de passage, peut laisser un mot sur une question précise, en encadré signé.

Comment ça se passe

D'un mois à l'autre, un livre relié

  1. Le débutVous créez le livre

    Quelle année, le nom de la famille pour le titre, qui raconte avec vous : les adultes reçoivent un lien, les enfants parleront depuis votre téléphone, un prénom et un âge chacun.

  2. Chaque moisChacun raconte

    Un rendez-vous chaque semaine, ou quand l'envie vient. Les questions suivent les saisons et rebondissent sur ce que chacun a raconté. Vous vous entendez les uns les autres par quelques extraits.

  3. Au douzième moisVous terminez

    L'app vous le propose au douzième mois ; vous terminez quand vous voulez. Le livre couvre ce qui a été raconté.

  4. Trois semaines plus tardLe livre

    Toutes les voix sont réunies, mois par mois, dans un livre relié, relu et validé en ligne, avec les QR codes pour les réécouter.
