4. La carte cadeau et le code

Sur la page de confirmation de commande, l'acheteur dit si le livre est pour lui ou s'il l'offre. S'il l'offre, il prépare une carte cadeau, à imprimer, à télécharger ou à envoyer par email ou par message. Elle porte un code d'activation unique, qui permet à la personne qui raconte d'ouvrir le livre dans l'app {{BRAND}}. Si le livre est pour lui, il s'ouvre dans l'app avec l'email de la commande, sans code.

Le code est personnel : l'acheteur le transmet à la personne de son choix et reste responsable de sa diffusion. La carte cadeau ne peut être échangée ni contre de l'argent, ni contre un autre produit. Elle vaut le prix du produit choisi ; il n'y a pas de carte cadeau à montant libre. Le code reste valable tant que le livre n'est pas validé, dans la limite de 24 mois (article 5).

5. Comment se déroule le service

Le service se déroule dans l'app {{BRAND}}, sur iPhone ou Android. Il faut un smartphone pour raconter ; les invités d'un livre Vœux, et les proches à qui une question est posée, répondent depuis un simple lien, sans compte.

Les rôles. L'acheteur paie et lance le livre. Le narrateur principal, celui qui active le code (ou l'acheteur s'il garde le livre pour lui), décide de tout ce qui concerne le livre : il choisit le titre, répond aux questions de paramétrage, invite les autres voix, termine le livre, le relit et le valide. Les narrateurs secondaires racontent avec lui depuis l'app. Les contributeurs éphémères répondent à une question précise depuis le lien, et leur message entre dans le livre dans un encadré signé de leur prénom. L'acheteur qui ne raconte pas n'a pas accès au livre : il est seulement prévenu que le code a été activé, puis que le livre est terminé. Pour les Mémoires seulement, il suit l'avancement, reçoit des extraits, peut poser ses propres questions, et peut relire et valider le livre si le narrateur principal l'y autorise.

Aucune durée n'est imposée pour raconter, sauf pour les Vœux, dont la collecte dure trois mois au plus, jusqu'à la date de fin fixée par le narrateur principal. Le livre est à valider dans les 24 mois qui suivent l'achat ; nous le rappelons à 18 et 23 mois. Passé ce délai, le livre est archivé : tout ce qui a été raconté reste téléchargeable pendant 12 mois, et le livre peut être réveillé pour 19 €. Un livre sans aucune réponse pendant 12 mois est mis en sommeil, sans rien perdre ; il se réveille d'un geste, gratuitement, tant que la validité court.

Le livre reprend les mots de ceux qui racontent : les histoires sont rangées, pas réécrites. Les souvenirs sont remis dans l'ordre, les répétitions retirées et les erreurs de langage corrigées, sans rien inventer. Le service peut être mis en pause ou arrêté à tout moment depuis l'app. [règle de remboursement en cas d'arrêt, notamment d'une grossesse : à écrire]
